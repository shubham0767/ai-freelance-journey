# Day 15 - Mini Projects & Revision

## 1. What have you learned in the first 15 days of Python?

In the first 15 days, I learned Python basics such as variables, data types, operators, conditional statements, loops, functions, lists, tuples, dictionaries, strings, file handling, object-oriented programming (classes, objects, inheritance), exception handling, modules, and packages. I also built several mini projects to apply these concepts.

---

## 2. Why are mini projects important?

Mini projects help us apply programming concepts in practical situations. They improve problem-solving skills, logical thinking, and confidence in writing complete programs.

---

## 3. Which Python concept do you find easiest?

I find variables, loops, and conditional statements the easiest because they are simple and frequently used in programs.

---

## 4. Which Python concept do you find most challenging?

Object-Oriented Programming (OOP), especially inheritance and method overriding, is more challenging because it requires understanding relationships between classes.

---

## 5. How do mini projects improve programming skills?

Mini projects combine multiple Python concepts into one application. They improve coding practice, debugging skills, and teach how to organize code for real-world problems.

---

## 6. What project did you enjoy building the most so far?

I enjoyed building the Student Management System because it combines dictionaries, functions, loops, and exception handling into one useful application.

---

# Key Points

- Mini projects strengthen programming concepts.
- They improve logical thinking and debugging skills.
- They help build a strong portfolio.
- Practice is the key to becoming a better programmer.
